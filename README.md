# GradeMate

เว็บช่วยคำนวณ GPA, GPAX, วางแผนเกรด และติดตามผลการเรียนสำหรับนักศึกษา

## Features

- GPA Calculator
- GPAX Calculator
- Target GPA
- Grade Calculator
- Semester History
- GPA Chart
- GPA Insights
- Dashboard
- Export / Import
- Responsive Design

## Privacy

GradeMate เป็นเว็บไซต์แบบ client-side ข้อมูลการเรียนถูกเก็บไว้ใน browser localStorage ไม่มี account ไม่มี cloud database และไม่มีการส่งข้อมูลการเรียนไป backend ผู้ใช้สามารถ Export / Import ข้อมูลเพื่อสำรองและนำกลับมาใช้ได้

## Technology
